## 📌 Постановка задачи и физико-химическая суть

Индекс селективности (**Selectivity Index, SI**) определяет терапевтическое окно противовирусного соединения и вычисляется как отношение цитотоксичности на клетках хозяина к противовирусной активности:

$$\text{SI} = \frac{\text{CC}_{50}}{\text{IC}_{50}}$$

* **CC50 (uM):** полумаксимальная цитотоксическая концентрация (безопасность для клеточных культур Vero, HeLa, HEL, BSC-40, MK-2).
* **IC50 (uM):** полумаксимальная ингибирующая концентрация против штаммов вируса осповакцины (Copenhagen, WR, Lister, IHD-J, Elstree).
* **Строгое соблюдение правил (Zero Leakage Guarantee):** столбцы CC50_uM и IC50_uM_VACV принудительно удаляются из входного пространства признаков до этапа препроцессинга и проверяются через assert. Предсказание для тестовой выборки строится исключительно на основе SMILES, strain, Culture и Title.

## 🚀 Архитектура решения

Пайплайн состоит из 5 специализированных модулей с бинарным кэшированием графов (step0_features.npz) и чекпоинтами предсказаний (step1.csv – step4.csv):

### 1. Сбор и гармонизация открытых баз данных (DATA/data_parser.py)
* Прямая многопоточная выгрузка (ThreadPoolExecutor, пакеты по limit=1000) через **ChEMBL REST API**.
* Фильтрация строго по мишеням поксвирусов (CHEMBL612862, CHEMBL613757 и др.) с исключением неспецифического пула Unchecked.
* **2D-канонизация графов (isomericSmiles=False):** устраняет расхождения в разметке 3D-стереоцентров (@/@@) между публичными базами и датасетом соревнования.
* Раздельная агрегация IC50 по штаммам Vaccinia virus и клеточно-специфичная привязка CC50 / TC50 внутри научных публикаций (document_chembl_id) с извлечением **DOI** (3,591 запись, 1,036 уникальных публикаций).

### 2. Молекулярная инженерия признаков (Step 0)
* **Комбинированные фингерпринты (2,727 бит):**
  * Morgan Fingerprints (ECFP4, радиус 2, 1024 бит);
  * Atom Pair Fingerprints (1024 бит) — улавливают фармакофорные расстояния;
  * Topological Torsion Fingerprints (512 бит) и MACCS Keys (167 бит).
* **Физико-химические 2D-дескрипторы RDKit (24 признака):** MolWt, MolLogP, TPSA, FractionCSP3, BertzCT, BalabanJ, индексы формы Kappa1–3, связности Chi0v–3v, лекарственное подобие QED и нелинейные отношения (MolWt/HeavyAtomCount, TPSA/MolWt).
* **Ядерные признаки Танимото (Tanimoto Similarity Kernel):** взвешенные по условному совпадению штамма и клеточной линии агрегаты ближайших структурных соседей со степенями ядра p = 2, 4, 6.
* **Выделение каркасов Бemis-Murcko (MurckoScaffold)** и символьная TF-IDF векторизация метаданных (strain, Culture, Title).

### 3. Четырехуровневый ансамбль градиентного бустинга (Steps 1–4)
* **Модуль 1 (step1.csv — Full-Scale Hurdle Ensemble):** комбинация классификатора активности P(active), полномасштабного регрессора CatBoost и ансамбля ExtraTrees + RandomForest для детекции сверхактивных серий (SI > 2000).
* **Модуль 2 (step2.csv — Decomposed CC50/IC50 Ratio):** раздельное моделирование цитотоксичности ln(CC50) и ингибирования ln(IC50) с восстановлением физического отношения.
* **Модуль 3 (step3.csv — Grandmaster pIC50):** бустинг в натуральной логарифмической шкале pIC50 для захвата наномолярных ингибиторов (IC50 ~ 0.01–0.05 uM).
* **Модуль 4 (step4.csv — Quantile alpha=0.82 + Multi-Booster):** верхний квантильный регрессор совместно с LightGBM и XGBoost (tree_method=hist), обученными с весами примеров w = 1 / group_size и признаками PCA-10 + мульти-масштабного KNN (k = 5, 15, 20).

### 4. Двумерная ядерная калибровка и подавление фонового шума (V6 Calibration)
* Компенсация регрессионного сжатия (Regression Attenuation) на тяжелом хвосте активных молекул через индекс согласованности ансамблей d / g и квантильный фильтр t / g.
* Подавление фонового шума (Shrinkage) на неактивных и слабоактивных соединениях (SI <= 50).

## ⚙️ Быстрый старт и воспроизведение результата

### 1. Установка зависимостей
```
bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

### 2. Выгрузка данных из открытых баз (ChEMBL)
```
bash
python DATA/data_parser.py
```

### 3. Запуск основного пайплайна и генерация submission.csv
```
bash
python solution.py
```

* При первом запуске скрипт извлекает молекулярные графы, обучает 4 модуля ансамбля с сохранением чекпоинтов в DATA/step*.csv и формирует submission.csv.
* При наличии готовых чекпоинтов финальная сборка и калибровка submission.csv выполняется за **0.15 секунды**.
* Подробный протокол выполнения с таймстемпами каждого этапа автоматически сохраняется в log.txt.
